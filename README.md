# VHDL Digital Logic Circuit Design

This repository contains five VHDL assignments for the Digital Logic Circuit Design course.

## Assignments
1. 4-Input AND and OR Gates
2. 8-to-1 Multiplexer
3. 7-Segment Alphabet Display
4. 25-Person Voting Machine
5. 13-Bit Population Counter with 7-Segment Display


## Files
- `VHDL/` — VHDL CODE (.vhd)
- `Logisim/` — VHDL1 (.circ)
- `Report/` — VHDL_1 assignment_2 (.pdf)
